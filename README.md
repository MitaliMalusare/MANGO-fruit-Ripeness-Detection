# Mango Ripeness Classification(CNN,Tensorflow,Matplotlib)

## Overview

This project aims to develop a Convolutional Neural Network (CNN) model to classify mangoes into two categories: Ripe and Unripe. The model is trained on a dataset of mango images, enabling automated ripeness detection to assist in quality control and inventory management.

## Dataset

The dataset consists of images categorized into two classes:

- **Ripe**: Mangoes that are fully matured and ready for consumption.
- **Unripe**: Mangoes that are not yet matured.

The images are pre-processed to center the face and ensure consistent sizing.

## Technologies Used

- **TensorFlow**: For building and training the CNN model.
- **Matplotlib**: For visualizing training and validation metrics.
- **Python**: The primary programming language.

## Training Results

- **Training Accuracy**: Approximately 99%
- **Validation Accuracy**: Approximately 97%
- **Test Accuracy**: Approximately 99%

## Evaluation

After training, the model achieves high accuracy on both validation and test datasets, indicating its effectiveness in classifying mango ripeness.
